## 📂 Lista de Projetos

| Projeto | Descrição |
|---------|-----------|
| [Projetos/ContadorCliques](/Projetos/ContadorCliques) | Contador decrescente controlado por interrupção usando a BitDogLab. Utiliza dois botões (A e B) e um display OLED para mostrar as informações. |
| [Projetos/LeitorJoystick](/Projetos/LeitorJoystick) | Leitura dos valores do joystick da BitDogLab (eixos X e Y e botão) e exibição dos resultados no display OLED. |
| [Projetos/MonitorTemperatura](/Projetos/MonitorTemperatura) | Leitura da temperatura interna do microcontrolador RP2040 usando seu sensor de temperatura integrado e exibição no display OLED. |
| [Projetos/ArquiteturaModular](/Projetos/ArquiteturaModular) | Sistema de controle do LED embutido da Raspberry Pi Pico W seguindo uma arquitetura modular de software com separação clara entre as camadas de hardware, abstração e aplicação. |
| [Projetos/PraticaTesteUnitario](/Projetos/PraticaTesteUnitario) | Implementação de uma função para converter leituras do ADC interno da Raspberry Pi Pico W para temperatura em graus Celsius, com testes unitários usando o framework Unity. |
